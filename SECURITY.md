# Security Policy

## 中文

这是一个基于 Markdown 的 Skill，默认不需要任何 API Key、访问令牌或账号凭据。

请不要在 Issue、Pull Request、测试样例或日志中公开：

- API Key、OAuth token、密码或 Cookie；
- 个人邮箱、手机号、真实地址或本地文件路径；
- 私有仓库内容或其他未授权数据。

如果你发现了会导致凭据泄露、未授权访问或危险误导的内容，请不要先公开发布。请通过 GitHub 私下联系维护者 [@TolyMarkee](https://github.com/TolyMarkee)，并提供最少必要的复现信息。

## English

This is a Markdown-based Skill and does not require API keys, access tokens, or account credentials by default.

Do not publish API keys, OAuth tokens, passwords, cookies, personal contact details, local file paths, private repository content, or other unauthorized data in Issues, Pull Requests, test cases, or logs.

For credential exposure, unauthorized-access risks, or dangerous misleading behavior, contact [@TolyMarkee](https://github.com/TolyMarkee) privately before public disclosure and provide only the minimum reproducible details.
