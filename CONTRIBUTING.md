# Contributing

感谢你关注 Project Model Advisor。

## 中文

欢迎提交文档修正、测试用例、Skill 规则改进和可复现的问题报告。

提交前请：

1. 说明修改的目标和适用场景；
2. 不提交 API Key、访问令牌、邮箱、个人路径或其他私密信息；
3. 更新相关测试输入、评分规则或测试日志；
4. 明确区分“已验证结果”和“待验证假设”；
5. 保持 Skill 的核心约束：不虚构模型能力、不承诺自动切换、不把历史自评当作成本证据。

建议先创建 Issue，再提交 Pull Request。小型拼写和文档修正可以直接提交 Pull Request。

## English

Contributions are welcome, especially documentation fixes, evaluation cases, Skill-policy improvements, and reproducible bug reports.

Before submitting:

1. Explain the goal and applicable scenario.
2. Never include API keys, access tokens, email addresses, local paths, or other private data.
3. Update relevant evaluation inputs, rubric entries, or test logs.
4. Separate verified results from unverified hypotheses.
5. Preserve the Skill's core constraints: do not invent model capabilities, claim an automatic model switch, or present historical self-assessments as measured cost evidence.

For substantial changes, open an Issue before a Pull Request. Small documentation fixes may go directly to a Pull Request.
